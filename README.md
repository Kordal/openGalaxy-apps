# openGalaxy apps

Signed Alpine (v3.24, aarch64) package repository and app catalog for the openGalaxy phone OS.
Served by GitHub Pages; the phone's Store app reads `store.json` and installs with `apk`.

    wget -O /etc/apk/keys/opengalaxy.rsa.pub https://kordal.github.io/openGalaxy-apps/opengalaxy.rsa.pub
    echo https://kordal.github.io/openGalaxy-apps/v3.24/og >> /etc/apk/repositories
    apk update && apk add ogfiles

Generated by `tools/store/publish.sh` in the (private) openGalaxy repo. Do not edit packages by hand.
